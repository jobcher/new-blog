#### 微软将在Windows Server 2028中默认移除32位应用支持
<p><b>微软将在Windows Server 2028中默认移除32位应用支持</b><br><br>微软在Ignite 2026大会上宣布，计划在2027年秋季发布的Windows Server 2028中，不再默认内置用于运行32位应用的WoW64兼容层。不过，对于仍有运行旧版业务软件需求的企业用户，微软保留了通过“按需功能（Feature on Demand）”手动重新安装该组件的途径。此外，新系统还将同步移除SMB1和VBScript等旧组件，并考虑取消对传统BIOS的支持。<br><br>微软团队表示，此举旨在应对当前日益严峻的网络安全挑战。随着人工智能工具大幅加速系统漏洞的发现，维护底层架构陈旧的遗留组件已难以保障安全，因此微软决定将系统的默认策略从“优先保证兼容性”转向“默认安全”，以减少32位恶意软件的攻击面。目前，面向个人消费者的Windows 11系统暂不受此调整影响，仍将继续默认提供对32位应用的完整兼容支持。<br><br>来源：<a href="https://www.windowscentral.com/microsoft/windows-11/microsoft-is-removing-32-bit-app-support-from-the-next-version-of-windows-server-wow64-subsystem-to-become-optional-component-to-reduce-malware-attack-surface" target="_blank" rel="noopener" onclick="return confirm('Open this link?\n\n'+this.href);">Windows Central</a></p>
