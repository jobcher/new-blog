#### 微软宣布 WSL Containers 正式发布
<p><b>微软宣布 WSL Containers 正式发布</b><br><br>微软近日宣布 WSL Containers（适用于 Linux 的 Windows 子系统容器）正式达到通用现售（GA）阶段。该功能旨在将 Windows 打造成运行和管理 Linux 工作负载的理想平台，开发者现可通过命令行工具 <code>wslc.exe</code>（别名 <code>container.exe</code>）或相关 API 直接在 Windows 上构建、运行和部署 Linux 容器。GA 版本不仅扩展了容器生命周期管理、网络连接与可观测性等多项核心功能，还将文件跨系统访问性能提升了最高 2 倍，并引入全新的 consomme 网络模式以优化兼容性。<br><br>来源：<a href="https://blogs.windows.com/windowsdeveloper/2026/09/29/wsl-containers-now-generally-available/" target="_blank" rel="noopener" onclick="return confirm('Open this link?\n\n'+this.href);">Windows Blog</a></p>
